# 세계관 구조 프레임 — 작품이 갖춰야 할 뼈대와 판정 기준

HEART SYNC의 작품(세계관·캐릭터)을 **만들 때의 순서**이자 **평가할 때의 잣대**예요. 새 작품은 이 틀을 채워서 만들고, 만든 작품은 이 틀로 판정해요.

| 문서 | 다루는 것 | 누가 봄 |
|---|---|---|
| [content/README.md](../../content/README.md) | 칸의 **모양** — `work.js` 문법, 폴더, 빌드가 검사하는 것 | 기계(빌드) |
| **이 문서** | 칸에 담기는 **이야기의 구조** — 무엇이 있어야 하고 무엇이 어긋나면 안 되는가 | 사람(판정) |
| [GUIDE.md](GUIDE.md) | **어떻게 쓰는가** — 걸음마다의 작법, 빈 뼈대, 흔한 결함 | 쓰는 세션 |
| `REVIEW-<날짜>.md` | 판정 기록 — 찾은 것·고친 것·남긴 것 | 주고받는 세션 |

기준은 2026-11-11에 있던 14작품을 모두 읽고 뽑았어요. 잘 짜인 작품에 공통으로 있는 것을 '필수'로, 얕은 작품에 빠져 있던 것을 '결함'으로 적었어요. 본문의 작품 이름은 본보기일 뿐이고, 기준 자체는 어느 작품에도 맞춰 있지 않아요.

## 1. 작품의 두 틀

| | 군상극(`world_mode: true`) | 1:1 |
|---|---|---|
| AI가 연기하는 것 | 내레이터 — 세계와 모든 인물 | 인물 한 사람 |
| 이야기를 끄는 힘 | **사건**(진상)과 **기한** | **관계**와 **사연** |
| 인물 | 주요 인물 다섯 안팎, 저마다 사건의 한 조각 | 한 사람의 겉과 속 |
| 설정 분량(persona+world+speech+secret) | 2,000자 넘게 | 800자 넘게 |

아래 기준에서 **[군]** 은 군상극에만, **[1]** 은 1:1에만, 표시가 없으면 둘 다에 적용해요. 진행 방식(끝이 열린 자유형 / 장과 결말이 있는 에피소드형)은 이 틀 위에 얹는 것이라, 에피소드형이어도 아래 여덟 층은 그대로예요(결말 갈래 E5만 `episode.endings`가 대신해요).

## 2. 모든 층에 걸리는 가로 규칙 다섯

### X1 가시성 — 칸마다 읽는 이가 달라요

| 읽는 이 | 칸 |
|---|---|
| **AI만** | `persona` · `world` · `speech` · `secret` · 시작 상황의 `directive`·`lead` · 명령어의 `prompt` |
| **독자**(AI도 읽음) | `oneLiner` · `desc` · `tags` · `guide` · `cast[].desc` · **`lore`의 첫 키와 `text`**(상세 페이지 세계관 카드에 처음부터 모두 보여요) · `places`의 이름·설명 · `cuts`의 제목·조건 · 명령어의 제목·설명·즉답 글 · 시작 상황의 제목·본문·첫 답변 추천·**상태창 초깃값(💭 속마음 포함)** |

- 진상은 AI만 읽는 칸에만 적어요. 독자가 읽는 칸에는 **겉으로 알려진 사실**(소문·공식 기록·눈에 보이는 것)과 **떡밥**까지만.
- 속마음은 독자에게 보이는 연출이에요. "무언가 숨긴다"까지만 적고 숨긴 **내용**은 적지 않아요.
- 화면 기준이에요 — 저장소가 공개라 파일을 열면 누구나 읽을 수 있어요.

### X2 떡밥–답 — 심은 물음에는 답이 있어야 해요

독자 칸과 시작 상황에 심은 물음(누가 했나·왜 그랬나·그것이 무엇인가)마다 셋 가운데 하나가 AI 칸에 있어야 해요.

1. **답** — 진상이나 `secret`, 그 시작 상황의 `directive`에 적혀 있다.
2. **위임** — "구체적인 내용은 유저 페르소나와 유저노트에 맞춰 정한다"처럼 누가 정하는지 적혀 있다.
3. **미지 선언** — "끝내 밝히지 않는다. 재해처럼 다룬다"처럼 답이 없음을 적어 두었다.

셋 다 없으면 AI가 방마다 다른 답을 지어내고, 장르가 틀어지기도 해요(현대 힐링물의 '이상한 소리'가 귀신이 됨).

### X3 정합성 — 같은 것은 어디서나 같아요

- 숫자: 나이, 날짜와 기한의 산수(`n일째`·`D-day`·남은 날), 수량.
- 호칭과 관계: 같은 낱말이 같은 사람을 가리켜요(예: '선왕'이 두 사람을 가리키면 안 됨).
- 규칙 문장: `world`·즉답 명령어·`guide`에서 글자까지 같아요.
- 시작 상황마다: 그 시점까지 지난 날과 상태창의 숫자가 엔진의 규칙과 맞아요.

### X4 안전

나이 지정은 트랙마다 달라요(2026-11-11 사용자 결정 — 전체이용가는 나이 제한 없이, 성인용에만 '모든 등장인물은 성인').

- **출연진(`cast`)은 어느 작품에서나 성인**이에요. 빌드의 `minorFlags`가 출연진의 외모·그림 태그와 설정 첫머리를 봐요. 출연진 묶음 머리에 "모두 성인"을 적고, 사람이 아닌 존재에는 "성인의 모습과 마음을 지녔다"를 붙여요.
- **그 밖의 인물**: 전체이용가(일반 트랙) 작품은 등장인물의 나이에 제한이 없고, 성인용(성인 트랙) 작품은 모든 등장인물이 성인이에요. 지금 `content/`의 작품은 모두 전체이용가예요.
- 어느 트랙에서든 **성인이 아니거나 그렇게 보이는 인물의 성적인 묘사와 그림은 어떤 경우에도 없어요.**
- **성인과, 성인이 아니거나 그렇게 보이는 인물 사이의 연애·성적인 관계나 장면은 쓰지 않아요.** 유저 캐릭터도 같고, 유저 캐릭터는 나이를 밝히지 않았으면 성인으로 봐요. 출연진이 성인이라, 유저 캐릭터가 성인이 아니면 출연진과의 연애는 쓰지 않아요.
- 성인이 아닌 인물끼리의 연애는 **고백·데이트·손잡기·포옹까지만** 써요(2026-11-11 사용자 결정).
- 수위는 암전이에요. 성인 수위의 글과 지시를 작품에 적지 않아요.
- 검사와의 관계: 단위 시험(safety)은 `content/`의 작품 글 전체가 미성년 암시 검사에 걸리지 않는지 봐요. 어린 조연의 나이·학년·교복 같은 표현을 적으면 그 시험이 걸리니, 전체이용가 작품에 그런 인물을 적어야 하면 먼저 그 시험을 어떻게 할지 맞춰요.

### X5 식별자

시작 상황 `id`와 인물 `code`를 정하고, 장소·컷씬·키워드북은 **맨 뒤에만** 더하고, 커밋 전에 `npm run content:lock`을 찍어요. 키워드북의 첫 키는 고치지 않아요(뒤에 키를 더해요).

## 3. 여덟 층

층마다 **무엇을 정하는가 → 어느 칸에 적는가 → 판정 기준** 순서예요. 기준 앞의 **필**은 필수(하나라도 미달이면 내보내지 않음), **권**은 권장이에요.

### L1 약속 — 독자가 들어오는 문 (`oneLiner` · `desc` · `tags` · `cat`)

| 기준 | 내용 |
|---|---|
| **P1** 필 | `oneLiner` 한두 문장에 ① 상황 ② 유저의 자리 ③ 걸린 것(기한·대가·물음) 가운데 둘 이상이 들어 있다 |
| **P2** 필 | `desc`는 무대·사건의 겉·인물 구도를 보여 주고 물음이나 열린 고리로 끝난다. 진상을 말하지 않는다 |
| **P3** 권 | `tags` 4~6개 — 장르·소재·관계 구도·분위기. 진상을 가리키는 낱말이 없다 |
| **P4** 필 | 소개 글이 건 약속마다 설정에 **이행 수단**이 있다(예: "당신의 의뢰는 그가 덮어 둔 사건과 이어져 있다" → 어떻게 이어지는지가 AI 칸에) |

### L2 유저의 자리 — 왜 하필 나인가 (`persona`의 [유저])

| 기준 | 내용 |
|---|---|
| **U1** 필 | 신분과 처지가 한두 줄로 정해져 있고, 성별·나이·외모는 유저 페르소나에 맡긴다 |
| **U2** 필 [군] | 남들이 못 하는 **수단 하나**(문서 감정, 지워진 글자 읽기, 현대 지식)와 **약점 하나**(신분, 누명, 막힌 힘) |
| **U3** 필 | "왜 하필 나인가"의 답이 진상이나 `secret`에 있다(명부에 적힌 이름, 품에서 나온 지도, 유언, 환생) |
| **U4** 권 | 유저가 정할 여백을 적어 두고(위임 문장), 필요하면 `noteTemplate`으로 양식을 준다 |

### L3 엔진 — 이야기를 굴리는 장치 (`world` · `fields` · `gauge`)

| 기준 | 내용 |
|---|---|
| **E1** 필 | [군] 기한 — 시작점·끝·하루의 구간·시간이 흐르는 규칙. [1] 기한이나 다가오는 고비 하나(계약 종료일, 공모전 마감, 함락 직전의 성) |
| **E2** 필 | 게이지 하나 — 무엇이 올리고 내리는지, **문턱에서 무슨 일이 벌어지는지**가 숫자와 사건으로 적혀 있다(80이면 자객, 100이면 하옥). [1]은 관계 게이지 |
| **E3** 필 [군] | 유저가 쓸 수 있는 수단 서너 가지와 그 대가 |
| **E4** 필 | 관계가 정보로 바뀌는 문턱. [군] 호감도 50에 단서·80에 비밀 같은 규칙. [1] 관계 게이지의 고비 두세 곳에서 무엇을 꺼내 놓는지 |
| **E5** 필 [군] · 권 [1] | 끝 — 결말 갈래 3~5개가 '무엇을 골랐는가'로 갈린다. [1]은 닿을 수 있는 끝 두세 갈래 |
| **E6** 필 | 상태창 칸이 엔진을 그대로 비춘다(시간·장소·모은 것·압력·관계·속마음). 시작 상황마다 모든 칸의 초깃값이 있다 |

### L4 진상 — 내레이터만 아는 것 (`persona`의 [진상] · `secret`)

| 기준 | 내용 |
|---|---|
| **T1** 필 | [군] 번호 붙은 사실 3~6개(누가·무엇을·어떻게). [1] `secret`에 숨은 사연과 **전말**(무슨 일이 있었고 왜 숨기는가) |
| **T2** 필 | 동기가 선다 — 범인·배후·숨기는 사람마다 '왜'가 한 구절씩 |
| **T3** 필 [군] | 조각마다 **닿는 길**이 있다 — 아는 사람(호감 문턱)이나 물증·장소. 둘이면 더 좋다 |
| **T4** 필 [군] | 공정성 문장 — "한 번에 풀리지 않되, 성실히 묻고 다니면 반드시 닿을 수 있게 단서를 공정하게 놓는다" |
| **T5** 필 | 떡밥–답(X2) — 시작 상황·키워드북·속마음·명령어에 심은 물음 전부에 답·위임·미지 선언 가운데 하나 |
| **T6** 권 [군] | 헛다리 — 가장 의심받는 무고한 인물 하나. 단서 하나로 범인이 바로 나오지 않는다 |
| **T7** 필 | `secret`은 진상의 요약이고 `persona`와 어긋나지 않는다(프롬프트의 '숨겨진 설정' 자리에 들어감) |

### L5 인물 (`persona`의 [인물] · `cast` · `speech`)

| 기준 | 내용 |
|---|---|
| **C1** 필 | 인물마다 역할(직업·세력) · 성격 두세 낱말 · 말투 · 상처나 사연 · 비밀 |
| **C2** 필 [군] | 인물마다 **사건 조각 하나** — 그 비밀이 진상의 번호 하나에 걸린다. 조각이 없는 인물은 장식 |
| **C3** 필 | 유저를 처음 어떻게 대하는지와 그 까닭(도구로 쓴다, 첩자로 의심한다, 감시한다) |
| **C4** 필 | 말투가 서로 다르다 — `speech`에 인물마다 말투 한 줄, 예시 대사 둘 이상 |
| **C5** 권 [군] | 인물끼리의 줄(동맹·질투·부채)이 하나 이상 — 유저 없이도 움직이는 관계 |
| **C6** 필 | 공개 소개(`cast[].desc`)에 비밀이 없다. `look`은 성인 나이와 외모 |
| **C7** 권 [군] | 역할이 겹치지 않는다 — 권력·무력·지식·정보·이단처럼 서로 다른 문을 연다 |
| **C8** 필 [1] | 겉과 속의 간극 하나, 대화의 손잡이(좋아하는 것·버릇) 둘, 피하는 화제 하나 |

### L6 무대 (`world` · `lore` · `places` · `cuts`)

| 기준 | 내용 |
|---|---|
| **S1** 필 | 장소가 엔진과 맞물린다 — 거점 하나, 인물·세력마다의 자리, 금지된 곳(숨긴 장소) |
| **S2** 필 | 키워드북은 **겉 사실의 층**이다. "실은…"과 진상을 적지 않는다(X1). 공정한 단서는 겉 사실로 심는다 |
| **S3** 권 | 키워드북 10개 안팎([1]은 5~6개), 종류가 셋 넘게 섞인다(인물·장소·물건·사건·세력·설정) |
| **S4** 필 | 세계의 규칙이 `world`에 인용할 수 있는 문장으로 적혀 있고, 숫자와 효과가 정해져 있다(능력의 값, 문턱, 수칙의 문장) |
| **S5** 권 | 컷씬 셋 — 첫 사건 · 숨긴 전환점(`hidden`, 제목은 에둘러) · 끝. `when`은 한 번만 일어나는 순간 |
| **S6** 필 | 미지로 둘 것은 미지라고 적는다(X2의 미지 선언) |

### L7 진입 (`openings`)

| 기준 | 내용 |
|---|---|
| **O1** 필 | 기본 시작 하나 — 첫 장면에서 유저의 처지·규칙·기한이 드러나고 첫 실마리가 남는다 |
| **O2** 필 | 변주 — [군] 다른 인물 축과 이야기 중반(단서 몇 개를 쥔 상태), 세 시작 상황에 주요 인물이 고루 나온다. [1] 거리가 다른 둘째 시작 상황 |
| **O3** 필 | 본문이 유저의 차례에서 멈춘다(질문·선택·위기) |
| **O4** 필 | `directive`에 드러낼 것·아직 감출 것·(중반이면) 이미 일어난 일, 그리고 **그 장면에 심은 수수께끼의 답**이 있다 |
| **O5** 필 | 상태창 초깃값이 그 시점의 산수와 맞고(X3), 속마음은 떡밥까지만(X1) |
| **O6** 필 | 배경 장소 `place`와 첫 답변 추천 셋 — 서로 다른 방향(묻기·행동·관계) |
| **O7** 필 | `id`는 뜻이 통하는 영문이고 공개한 뒤 고치지 않는다(X5) |

### L8 운영 — 이야기가 굴러가는 손잡이 (본문 표식 · `commands` · `guide` · `noteTemplate`)

| 기준 | 내용 |
|---|---|
| **R1** 필 [군] | 본문 표식 하나 — `[단서: …]`처럼 모은 것이 본문에 한 줄로 찍힌다(`speech`에 적음). 상태창과 정리 명령어가 이것을 받는다 |
| **R2** 필 | 명령어 둘에서 셋 — **정리형**(모은 것 정리, "새로 지어내지 않는다"는 문장이 있음) · **전환형**(이 작품의 되풀이 단위로 장면을 넘김) · **즉답**(규칙·계약서 — `world`와 같은 글) |
| **R3** 필 | `guide` — 무슨 이야기인지 한 줄, 시간·게이지·표식·명령어 안내, 끝이 무엇으로 갈리는지. 진상이 없다 |
| **R4** 권 | `noteTemplate` — 유저가 정할 여백을 양식으로 |

## 4. 판정하는 법

1. 작품을 처음부터 끝까지 읽어요(`work.js` 한 파일).
2. 기준마다 ○(충족) · △(일부) · ✕(없음·어긋남)을 매기고, △와 ✕에는 **어느 칸의 어느 문장인지**를 적어요. 근거 없는 판정은 판정이 아니에요.
3. X2(떡밥–답)는 따로 표를 만들어요 — 독자 칸과 시작 상황에서 물음을 모두 뽑고, 물음마다 답이 적힌 자리를 찾아요.
4. X3(정합성)은 숫자를 다 뽑아 견줘요 — 나이, 날짜, 기한, 수량, 호칭.
5. **필수에 ✕가 하나도 없으면 내보낼 수 있어요.** △는 고칠 곳으로 적어 두고, 권장은 다음 손질 때 봐요.
6. 판정과 고친 것을 `REVIEW-<날짜>.md`에 남겨요(찾은 것 → 고친 것 → 남긴 것, 새로 지은 사실은 따로 목록으로).

층의 순서가 곧 만드는 순서예요. 걸음마다 관문의 물음에 답할 수 있어야 다음으로 가요(자세한 작법은 [GUIDE.md](GUIDE.md)).

| 걸음 | 정하는 것 | 관문 — 이 물음에 한 문장으로 답할 수 있나 |
|---|---|---|
| 0 자리 | 대상(`f`·`m`·`all`), 홈 줄, 틀(군상극·1:1), 진행(자유형·에피소드형), 있는 작품과 겹치지 않는 소재 | 지금 서가에 없는 무엇인가 |
| 1 약속 | 한 줄 고리 | 누가, 무엇에 쫓겨, 무엇을 하러 들어오는가 |
| 2 유저의 자리 | 처지·수단·약점 | 왜 하필 이 사람이어야 하는가 |
| 3 엔진 | 기한·게이지·수단·끝 | 가만히 있으면 무슨 일이 벌어지는가 |
| 4 진상 | 조각표(사실·동기·아는 사람·물증) | 다 풀었을 때 독자는 무엇을 알게 되는가 |
| 5 인물 | 조각을 나눠 쥔 사람들 | 이 사람을 빼면 어느 조각이 사라지는가 |
| 6 무대 | 장소·규칙·키워드북(겉 사실) | 독자가 처음부터 볼 수 있는 것과 없는 것은 |
| 7 진입 | 시작 상황 셋 | 첫 장면에서 유저가 답하지 않을 수 없는가 |
| 8 운영 | 표식·명령어·가이드 | 막혔을 때 독자가 누를 손잡이가 있는가 |
| 9 검사 | 기계 검사 → 자기 판정 → 검토 요청 | 필수에 ✕가 없는가 |

걸음 9의 흐름: 세계관 세션이 만들고 스스로 판정 → 평가 세션이 판정하고 보강 초안을 냄 → 세계관 세션이 받아들이거나 고침 → 병합 담당이 올림([docs/TEAM.md](../TEAM.md)).
