## 2. 신님들 — 다른 곳에서 만든 탑 이야기와 합치기

사용자가 다른 곳에서 만든 탑 이야기(재앙 뒤의 탑 · 층마다 쉼터 · 관객 같은 신들의 후원 · 요정 안내원 · 1층 생존자 무리)는 신님들과 뼈대가 같아요. **이야기의 장치만** 들이고, 다른 웹소설의 낱말(성좌·스트림 같은 것)은 쓰지 않고 이 작품의 극장 말(관람신·막·분장실·프롬프터)로 옮겼어요. 그쪽의 주인공 이름과 경력은 가져오지 않았어요(커스텀 모드의 예시도 일반적인 것으로).

| 들인 것 | 신님들에서의 모양 |
|---|---|
| 층마다 한 번뿐인 쉼터, 돌아갈 수 없음 | 막간의 쉼터는 층마다 한 번 · 막의 문은 한 방향 · 3의 배수 층의 쉼터는 '분장실'(관람신과 대면·계약 흥정) |
| 되돌릴 수 없는 난이도, 헬의 숨은 조건 | 난이도는 되돌릴 수 없고 높다고 보상이 보장되지 않음 · 헬 특수 조건 '아직 객석에 앉지 않은 관객의 시선을 견뎌라'(진상 ⑦ — 좌석 없는 거래를 거절하고 3층 클리어 → [희귀] 객석 없는 시선) |
| 대가가 있는 후원, 익명 후원 | 후원은 조건을 건 제안 · 실명 후원에는 좌석(A열 7번) · 익명 후원은 이름과 좌석을 가림 · 좌석 없는 승인은 정상 권한 밖의 개입(진상 ③) |
| 새 신 셋 | 겨울밤의 방랑자 · 맹세가 부러진 기사(첫 공연의 증인 — 진상 ⑥) · 달빛 아래 춤추는 여인(관계에 값을 매김) |
| 요정 안내원 | 프롬프터 루미(성인의 모습과 마음, 전지전능하지 않음, 진상 모름) |

| 숨은 특성 | 잠재 기록 — 유저노트의 경력·특기에 맞춰 정하고 개화하면 [고급] |

## 3. 새 작품 — 《F급 던전, 오늘도 영업합니다》(content/m/fdungeon)

- **고른 까닭**: 웹소설 흐름에서 회귀의 세분화·던전 경영·퇴마·시스템 로판이 강하고(스토리벤치 2026 장르 정리), 캐릭터챗에서는 자유도와 기억이 높게 평가돼요(지스타 2026 크랙 — 무림영웅전·스탯몰빵용사). 서가에 '키우는 이야기'가 비어 있었어요(신님들은 오르는 이야기, 생존 줄은 버티는 이야기).
- **Codex와 정한 것**: Codex의 첫 다섯 안은 장부·감독관 위주로 채팅의 손맛이 약했고, 세계관 세션이 '함정을 깔고, 몬스터 직원을 키우고, 손님이 비명 끝에 다시 오는' 쪽으로 틀을 바꾸자고 제안 → Codex가 뼈대(손님이 바라는 것 하나 · 유저가 연출할 구역 하나 · 기억할 인물 하나)를 냄. 세계관 세션의 '다회귀 군상극' 안보다 이 플랫폼에 맞다는 데 둘이 동의.
- **뼈대(FRAME 여덟 층)**: L1 약속 — 재심사까지 서른 날, 망해 가는 F급 던전 · L2 자리 — 대리 마스터(코어 시야·DP로 구역 바꾸기 / 밖에서 하루를 넘기면 각인이 풀림, '몬스터 편' 의심) · L3 엔진 — 하루 = 오픈 준비 → 한 파티 → 마감 회의, ⭐ 평판(30 시작·60 통과, 20 이하 봉인, 0 시범 감사만), 💠 DP · L4 진상 ①~⑤(아래) · L5 인물 다섯(무력·구조 / 기술 / 정보 / 바깥 시선 / 제도) · L6 장소 여섯(코어실 거점, 접힌 대피로 숨긴 곳) · L7 시작 상황 셋(1일차 / 4일차 봉인 / 11일차 종소리) · L8 명령어 셋(!마감장 정리 · !다음영업 전환 · !영업규칙 즉답).
- **진상 조각표**

- 결말 넷(world): 독립(재심사 통과) · 위탁(30일차 전에 아크라인 제안을 받아들임) · 이전(마두식과 휴대 코어를 되찾고 직원 동의 → 영업권 반납 뒤 새로 엶) · 정리(셋 다 아니면).
- **Codex 검토(판정: 보강 후 공개 → 고쳐 넣음)**
  - 엔진: DP 수입의 근거(무사 완주 1 · 바람 충족 2 · 기억에 남는 장면 +2 · 구조나 위반이 있던 날 0) · 구조와 위반이 겹치면 −15만 · 정산은 마감 때 하루 한 번 · 처음 20 이하면 시범 회랑 봉인(시범 감사 성공으로 풂) · **평판 0의 막다른 길**(시범 한 번을 잘해도 60에 못 닿음) → 재개용 시범 감사 한 번, 성공하면 30으로 다시 엶 · 시범 감사의 신청과 성공 조건(유담이 손님으로 함께 걸음) · 결말마다 들어가는 조건.
  - 손맛: 입장 전에 유저가 고르는 것(방 하나 고치기나 그대로 · 직원 역할)과 입장 뒤 할 수 있는 것(직원에게 신호 · 안내 방송 · 비상 퇴장, 위험하면 유저 차례에서 멈춤) · 연출이 맞으면 손님이 바라던 행동을 직접 해 볼 기회 → 무사 완주와 함께일 때 재예약.
  - 진상의 발견 경로: ③ 문 기록은 복제 키가 쓰인 것까지만 보여 줌 → 비오가 지우지 못한 메시지 · ④ 종을 다시 거는 법을 알 사람이 없음 → 종 안쪽 공방 각인 = 퇴장 데크 점검 패널의 표지(세라가 알아봄), 패널 안의 복구 순서 · 마두식이 대피로에 들어간 까닭(이전 준비)과 잠근 사람을 본 점검창 · ⑤ 유담이 위탁 이의 접수 절차로 공문 날짜와 코어 회수 이력을 열람시킴.
  - 노출: 1일차 첫 장면이 각인 조건(진상 ①)을 그대로 읽어 줌 → '승계 조건을 충족한 사람을 찾았습니다'로 · 코어 시야는 영업 구역까지(접힌 대피로는 밖).
  - 시작 상황: 4일차·11일차의 DP와 평판 장부를 directive에 적음 · 4일차 나린은 이미 취소했고 다시 들어올지 떠보러 옴 · 11일차 노부부의 '40년 전 첫 던전'은 던전 20년과 어긋남 → '스무 해 전' · 날짜 기준을 1일차로 하나(키워드북의 '3주 전'·'사흘 전'은 날이 지나도 맞게).
  - 운영: !마감장을 두 번 불러도 정산은 한 번 · 영업 중에는 장면을 끊지 않음 · !다음영업은 남은 선택이 있으면 멈추고 30일차 뒤엔 재심사로 · 상태창에 📌 단서 칸.
  - 다시 찾아오게 할 장면 둘(다친 신입이 직접 예약 · 카메라 앞의 가온)을 persona에 씨앗으로.
  - 세계관 세션이 고쳐 받은 것: Codex의 긴 문장은 절반쯤으로 줄임 · 숨긴 컷 '고물 더미의 종'의 조건은 그대로(11일차 첫 장면에 이미 나오는 장면이라 진상이 아님) · 인물별 호감도 문턱(50·80)은 world의 공통 규칙과 겹쳐 빼고 · 그림 태그의 girl → adult woman 제안은 이미지 세션에 넘김(화풍과 생성 값은 이미지 세션 몫).
- 그림: 출연진·장소·컷씬·키워드북의 영문 태그를 적고 이미지 세션에 프롬프트 작성과 시험 생성을 의뢰함(결과는 이미지 세션이 따로 알림).

## 4. 이번에 새로 지은 사실

1장 표의 '고친 것' 칸과 2·3장이 모두 새로 지은 사실이에요. 사용자에게 따로 확인받지 않은 채 들어간 것이라, 마음에 들지 않는 것이 있으면 그 줄만 되돌리면 돼요(작품마다 한 커밋 안에 있음).
