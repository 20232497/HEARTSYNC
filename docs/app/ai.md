# AI 호출·대화 트랙·요금

모델을 부르는 길(ai/llm.js), 한 방은 한 트랙이라는 틀과 서버 대화 관문, 모델 시험에서 메운 것, 일반 트랙의 무료 길, 요금 계산. 모델 후보와 비용은 [docs/COMMERCIALIZATION.md](../COMMERCIALIZATION.md), 남은 과제는 [docs/ROADMAP.md](../ROADMAP.md).

> CLAUDE.md의 지도 표가 가리키는 **영역 문서**예요. 이 영역의 코드를 고치기 전에 읽고, 고친 뒤에는 같은 커밋에서 이 문서의 해당 항목을 고쳐요. 항목은 2026-11-12에 CLAUDE.md의 '앱 구조'·'소스 구조·빌드' 절에서 문장 그대로 옮긴 것이고, 결정의 날짜와 경위를 모은 색인은 [docs/DECISIONS.md](../DECISIONS.md)에 있어요.

**이 문서가 다루는 모듈**: `src/js/ai/llm.js` · `src/js/ai/models.js` · `src/js/ai/stream.js` · `src/js/core/wallet.js` · `src/js/core/config.js` · `src/js/ui/pay.js` · `src/js/ui/model-sheet.js` · `src/js/ui/store.js` · `docs/edge/chat.ts` · `tools/model-bench.mjs` · `tools/prompt-bench.mjs`

## AI 호출

- AI 호출(ai/llm.js): llm(messages, {tier, onText, signal, json, maxTokens}) → Anthropic 스트리밍(사용자 키, 또는 CFG.anthropicUrl 프록시 + serverKeys). 키가 없으면 {code:"no_engine"}. 모델 ID claude-haiku-5-5·claude-sonnet-5-5·claude-opus-5-5(MODEL_OF quick·default·complex — claude-3-x로 되돌리지 않기). Sonnet·Opus 요청에는 server-side fallback(fallbacks: "default", 헤더 server-side-fallback-2026-07-01, 기본 Anthropic 주소일 때만, 400이면 빼고 한 번 재시도). stop_reason "refusal"은 {code:"refused"}. **생각(thinking) 설정 THINKING**(ai/llm.js): 이 세대 모델은 생각이 기본으로 켜져 있고 생각 토큰도 max_tokens에서 빠져, 그대로 두면 본문이 잘리고 상태창이 빠짐(2026-11-10 실측: Sonnet 기본 effort high가 3,200 중 2,051을 생각에 씀) → 요청에 output_config.effort "low", 출력 한도에 생각 몫 room 2,000을 더함(실측: Sonnet low 생각 약 1,200·Haiku low 0). 끝난 이유(stop) 없이 닫힌 스트림과 스트림 안의 error 조각은 끊긴 답 → upstream_error(하트 환불). 네트워크 시간 제한 TIMEOUT(connect 45초·stall 60초·api 20초, timeoutSignal·abortCode) — 시간 초과는 {code:"timeout"}, 끊기면 받은 본문까지 남기고 '다시 시도'. 오류 문구는 errCopy

## 대화 트랙

- 대화 트랙(2026-11-09, 투트랙의 대화 경로 틀 — 아직 꺼져 있음): **한 방은 한 트랙으로만**. ai/models.js trackOf(r) = 작품 사본 r.char.track("adult"만 성인, 그 밖은 general) — 방을 만들 때 굳고, 한 방 안에서 모델을 오가지 않음(이유: Claude 쪽에 성인 글이 섞여 들어가지 않게·말투 일관·판정 지점 하나·성인 후보 모델이 Sonnet보다 싸서 섞어도 아낄 게 없음). llm(…, { room })이 갈라 보냄 — 일반은 Anthropic(위), 성인은 서버 대화 관문 CFG.chatUrl(기본 "" = 꺼짐 → no_gateway '준비 중')으로만, 실패해도 Anthropic으로 돌리지 않음. **본문·요약·추천 모두 room을 넘겨야 같은 경로**(빠뜨리면 일반 경로로 감). 관문 = Supabase Edge Function docs/edge/chat.ts(올리는 순서 docs/SETUP.md '대화 관문 설정'): 로그인 → 요청 모양(track adult만) → 성인 인증 adult_checks(성인·만료 전, 시험 채널은 CHAT_ALLOW_TEST_IDV=1일 때만) → 미성년 암시 messagesMinorHint(core/safety.js를 배포된 사이트에서 import — 못 가져오면 함수가 안 뜸, 판정이 없거나 오류면 막음) → 하루 한도(표 chat_usage·함수 bump_chat_usage, CHAT_DAILY_LIMIT 기본 300) → 모델 서버(OpenRouter)의 OpenAI 호환 스트림을 그대로 중계(읽기는 ai/stream.js openaiEvent). 모델 이름(CHAT_MODELS)·성인 트랙 머리말(CHAT_PREAMBLE_ADULT)·키는 서버 환경 변수에만 — 저장소·배포물에 없음. 브라우저는 보내기 전에 관문 주소·로그인·roomMinorHint만 미리 봄(판정은 서버). rulesPrompt의 수위 줄은 트랙마다 다름 — 성인 트랙은 '모든 등장인물은 성인'(새 인물도)만, 일반 트랙은 '미성년(성인이 아니거나 그렇게 보이는 인물)의 성적 묘사는 어떤 경우에도 금지, 성인과 미성년 사이의 연애·성적 장면 금지(유저 캐릭터도 — 나이를 밝히지 않았으면 성인으로 봄), 미성년끼리의 연애는 고백·데이트·손잡기·포옹까지'와 '암전'(2026-11-11 사용자 결정 — 아래 원칙의 수위). content/의 작품에 track을 적으면 빌드 실패(공개 저장소는 일반 트랙만) — 성인 작품을 싣는 길(팩 형식·검사기·로더)과 성인 인증 화면은 아직 없음. 서버 판정은 roomMinorHint보다 한 곳 엄함(키워드북 종류를 몰라 동물의 나이도 막음). 시험: tests/unit/chat-gate·stream·safety(오리지널의 실제 프롬프트가 서버 판정을 통과하는지), e2e tracks
- 모델 시험과 그때 메운 것(2026-11-09, 도구 tools/model-bench.mjs — 앱의 buildInput·llm·parseState와 관문 handle을 그대로 거쳐 진짜 모델 서버를 부름, 키는 환경 변수 OPENROUTER_API_KEY, 내용은 공개 작품과 평범한 입력만): ① 생각(reasoning) 토큰도 출력 한도에서 빠져 본문 0자로 끝나는 모델이 있음 → 관문이 reasoning 기본 `{effort:"low"}`를 보내고, CHAT_MODELS의 값이 `{model, reasoning}`이면 그 설정('끄기'는 끌 수 없는 모델에서 400, '낮게'로도 한도를 다 쓰는 모델은 못 씀) ② 답 없이 주석 줄(keep-alive)만 보내는 스트림이 끝나지 않음 → 시간 제한은 data 줄이 올 때만 다시 셈(ai/stream.js readSSE), 성인 트랙은 첫 글자 전까지 TIMEOUT.think 150초·그 뒤 stall ③ 본문 없는 응답은 upstream_error(환불 — 일반 트랙도 같음) ④ Claude가 아닌 모델은 기록 속 응답이 본문으로만 끝나면 상태창을 빼먹음 → buildInput이 **직전 응답 하나에 그때의 상태창을 출력 형식 그대로 붙이고**(추천이 없던 응답엔 보기 셋), [이번 응답] 끝에 MARK로 마치라는 한 문장(일반 트랙에도 같음 — 입력이 150토큰쯤 늚). 결과와 고른 모델은 docs/COMMERCIALIZATION.md 7장 — 영어 중심 역할극 파인튜닝은 한국어가 깨져 탈락
- 일반 트랙의 무료 길(2026-11-09, 꺼진 상태 — 사용자 방향 '기본 무료 모델을 두고 나머지 모델 선택은 베이비챗 형태로'의 첫 걸음): 같은 관문이 `track: "general"`도 받음 — 성인 인증·미성년 판정 없이 로그인과 하루 한도(CHAT_FREE_DAILY_LIMIT 기본 80, chat_usage는 계정·날짜·**트랙**별)만 보고 회사 키(ANTHROPIC_API_KEY)의 Claude로 감(요청·스트림은 앱이 자기 키로 부를 때와 같은 Anthropic 모양, 머리말 없음. 생각 설정은 앱의 THINKING과 같은 값을 관문이 따로 둠(chat.ts THINK — effort low, 요청받은 본문 몫에 room 2,000을 더해 max_tokens로: 2026-11-11, 없으면 생각 토큰이 한도를 먹어 본문·상태창이 잘림. 단위 시험 chat-gate가 두 값이 같은지 봄 — 한쪽을 바꾸면 다른 쪽도)). 서버의 CHAT_MODELS.general에 있는 등급만(처음엔 quick = Haiku 하나) — 없는 등급은 `need_key`, general 표나 키가 없는 서버(성인 트랙만 켠 경우)는 앱이 `no_engine`(키를 넣으라는 안내)으로 바꿈. 앱의 갈림(ai/llm.js): 일반 트랙에서 **내 키(또는 serverKeys)가 있으면 지금처럼 Anthropic으로 바로, 없고 CFG.chatUrl이 있으면 관문**(로그인 없으면 `login_free` 안내). hasClaudeKey()는 chatUrl도 '연결 있음'으로 봄(홈의 키 안내 띠가 사라짐). 무료 모델 후보는 같은 시험으로 잼 — Claude Haiku 5.5가 형식 7/7·7~13초·턴당 약 ₩1.3~3으로 가장 맞았고, OpenRouter의 `:free` 변형은 첫 요청부터 429라 서비스 기본값으로 못 씀. 하트·무료 턴 계산은 여전히 브라우저(데모) — 서버 한도가 실제 상한. 남은 것: 서버가 모델 표를 내려주고 이름으로 고르기, 서버 원장 뒤에 유료 모델을 회사 키로, 켤 때 방침·FAQ 갱신
