# 프롬프트·응답 형식·에피소드

응답 형식(===STATE===)과 그 파싱, 시스템 프롬프트의 세 블록·키워드북·장기기억, 에피소드형 작품과 외전. 프롬프트 글을 고치면 단위 시험 rules·input·lore·episode가 지켜요.

> CLAUDE.md의 지도 표가 가리키는 **영역 문서**예요. 이 영역의 코드를 고치기 전에 읽고, 고친 뒤에는 같은 커밋에서 이 문서의 해당 항목을 고쳐요. 항목은 2026-11-12에 CLAUDE.md의 '앱 구조'·'소스 구조·빌드' 절에서 문장 그대로 옮긴 것이고, 결정의 날짜와 경위를 모은 색인은 [docs/DECISIONS.md](../DECISIONS.md)에 있어요.

**이 문서가 다루는 모듈**: `src/js/ai/parse.js` · `src/js/ai/prompt/rules.js` · `src/js/ai/prompt/episode.js` · `src/js/ai/prompt/input.js` · `src/js/ai/prompt/lore.js` · `src/js/ai/prompt/memory.js` · `src/js/core/episode.js` · `src/js/ui/chat/episode.js` · `src/js/ui/chat/generate.js`

## 응답 형식

- 응답 형식: 본문 + MARK("===STATE===") + 상태창 JSON → parseState()가 나눔. 요청 형식은 바꾸지 않기. 받는 쪽은 관대하게: splitReply(변형 구분자·구분자 없는 {"status"…}·```json)·repairJSON(끊긴 JSON)·mergeMulti(다인원 칸에서 빠진 인물은 직전 값, 한 사람당 -10~+8, 이름에 숫자 아닌 글자가 있어야 짝). JSON 뒤에 붙은 [[img:…]]는 본문으로, 추천 답변 앞 번호는 뺌. 빈 값은 직전 값을 덮지 않음
