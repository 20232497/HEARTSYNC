# 그림 코드·도감·세계관

그림 하나 = 코드 한 토큰이라는 체계와 그 해석(codebook), 장면 그림 고르기, 도감 화면, 세계관 일러스트와 세계관 수첩. 그림의 규격과 의뢰 목록은 [docs/app/content.md](content.md), 큰 흐름은 [docs/ARCHITECTURE.md](../ARCHITECTURE.md) '그림을 싣는 길'.

> CLAUDE.md의 지도 표가 가리키는 **영역 문서**예요. 이 영역의 코드를 고치기 전에 읽고, 고친 뒤에는 같은 커밋에서 이 문서의 해당 항목을 고쳐요. 항목은 2026-11-12에 CLAUDE.md의 '앱 구조'·'소스 구조·빌드' 절에서 문장 그대로 옮긴 것이고, 결정의 날짜와 경위를 모은 색인은 [docs/DECISIONS.md](../DECISIONS.md)에 있어요.

**이 문서가 다루는 모듈**: `src/js/images/codes.js` · `src/js/images/situations.js` · `src/js/images/pick.js` · `src/js/ui/cover.js` · `src/js/ui/codex.js` · `src/js/ui/worldart.js` · `src/js/ui/detail.js` · `src/js/ui/room-tools.js`

## 그림 코드 체계

- 그림 코드 체계(2026-11-08, 참고 사이트 ERANOS의 RIA2식 — 메모리 '참고 사이트'): **그림 하나 = 코드 한 토큰** `<인물코드><번호>`. 인물 코드는 cast[].code 영문 대문자 1~4자(HSY 한서윤·KAS 카시안 — 작품별 표는 content/README.md), 번호는 SIT 0~14(프로필·기본·웃음·부끄러움·슬픔·놀람·분노·삐침·공포·부상·회복·휴식·공격(맨손·무기 모두)·각성·설렘). 본문 태그 `[[HSY3]]`, 파일 `HSY3.webp`. 예약 시리즈 `MP<n>` 장소(작품 places의 n번째)·`EV<n>` 컷씬(cuts의 n번째, 1부터). 다른 모습(폼)은 번호가 아니라 별도 인물 코드(cast[].of = 본체). 1:1 작품도 cast 한 명(BY·KAEL·SDY·HGU·YHR), cast를 빼면 앱이 코드 C를 만듦. **해석의 단일 출처는 codebook(c)**(images/codes.js — 코드 글자 → {kind, name, of, min, max, items, field, nameKey, hidden}; 시리즈를 더하려면 SERIES에 한 줄) — 프롬프트·렌더러·갤러리·빌드 검사(APP_RULES codebook)·도감이 모두 이것으로 해석. 작품은 데이터(cast·places·cuts·commands·cast[].desc)만 적고 틀은 작품 수와 무관(메모리 '프레임 우선 방침'). **비공개(스포일러) 플래그**(화면에서만 가리는 장치 — 데이터와 그림은 배포물에 그대로 실림, 완전한 비공개는 서버 조립 뒤: 2026-11-09 결정): cast[].hidden(감정 번호 배열)·places[].hidden·cuts[].hidden(참거짓) → codebook 항목의 hidden(번호 배열) 하나로 해석 — 도감·상세의 미리보기와 장소 목록(!지도)은 그 번호의 **그림만** 🔒로 가리고(장소·컷씬의 이름·설명은 보임 — 2026-11-09 결정. 그림이 없거나 잠긴 장소·컷씬 카드는 그림 자리를 낮은 띠로 — 37-codex.css `.codex-grid .wpic.ph`, 2026-11-10 결정), **대화에서 한 번 본 그림은 그 뒤로 도감·상세·장소 목록에서도 열림**(2026-11-09 사용자 결정 — 본 기록은 내 서재의 수집 기록 S.shelf.seen — docs/app/storage.md '내 서재'). 본문 렌더(tagInfo)·프롬프트는 가리지 않음
- 장면 그림 코드: images/codes.js(순수): CODE_RE·SERIES·codebook·IMG_TAG_RE(새 [[HSY3]]·[[img:HSY3]]와 예전 [[img:p1:3]]·조합 "3,404,501" 모두)·imgTags → {code(대문자), sit, raw}·imgTag·codeKind·sitOf(예전 번호)·fallbackSits(인물 그 칸 → 1 → 0, MP·EV는 그 번호만). images/situations.js: sitName·sitScores·sitHints(낱말 점수). images/pick.js: imagesOf(코드 글자 → 번호 → 경로)·pickImg. ui/cover.js: tagInfo(c, t) → {kind, name, label, ref}(인물은 방 사본, 장소·컷씬 목록은 최신 작품)·figHTML(c, t) → figure.scene-img[.place|.cut][data-code][data-sit], 그림이 없으면 artHTML(색 카드 + 칸 이름/장소/컷씬). 응답이 끝나면 addCastImages(ui/chat/generate.js)가 태그를 빠뜨린 인물(폼은 본체와 한 사람)에 [[코드번호]]를 붙임(처음 등장은 0, 아니면 그 인물 줄·유저 입력의 낱말 점수, 그림이 있는 칸 가점, 최대 5장). 여러 장이면 many-img, 글 없이 이어진 그림은 .scene-row. 예전 방은 migrateRoom(core/rooms.js upgradeCodes)이 열 때 같은 이름의 인물로 코드·태그를 바꾸고 저장(층 규칙 때문에 예전 태그 정규식은 그 안에 따로). ## 도감

- 도감(ui/codex.js, CSS 37-codex): **독립 메뉴 #codex(·#codex-<작품id>) viewCodex** — 공통 표(그림 코드 읽는 법·감정 칸 0~14 색 칩·공통 명령어 카드 — 배지 앱·연출) + 작품 칩(관심있는 대화 audOK로 거름, 없으면 첫 작품) → 그 작품의 인물 카드·장소 MP·컷씬 EV·작품 명령어. 내비 USER_NAVS는 여섯 개(홈·대화·도감·공지·스토어·MY — 도감은 셋째, 아이콘 book). 상세 페이지(ui/detail.js — 칸 순서: 시작 상황과 새 대화 시작·내 대화방 → 소개·플레이 가이드·명령어 → 그림이 있는 칸인 등장인물·장소·컷씬·세계관 일러스트. 2026-11-11 사용자 요청 '새 대화를 소개 위에, 명령어를 가이드 아래에, 그 뒤로 그림을 이어서')도 같은 조각을 씀: castGridHTML(본체만, 코드 칩)·bindCast → castSheet(코드·외형·desc 소개·다른 모습 칩·감정 칸 칩 — 그림이 준비된 칸 ●·비공개 칸 🔒, 누르면 그 칸만 미리보기(대체 없음, 비공개는 카드))·placesHTML(장소·컷씬 칸 — 있을 때만)·commandsHTML(명령어 카드 = allCommands — 앱·연출·이야기 배지, 복사 버튼; 둘을 이어 붙인 것이 codexHTML)·bindCodex, 등장인물 머리에 '도감' 버튼(#codex-<id>). **작품 메타**(work.js creator·exclusive·publishedAt): metaHTML(c) 한 줄 — 제작자(없으면 core/constants.js DEFAULT_CREATOR)·공개일·'독점' 배지를 상세 페이지 머리와 도감 작품 칸에(홈 카드에는 없음, 표시만 — 제작자 보상은 서버 원장 뒤. 2026-11-09 결정값은 docs/ROADMAP.md 5장: 기본 10%·독점 25%에서 시작·신작 +5%p(공개 후 30일)·작품당 500턴 뒤 활성·제작자 본인 사용분 제외·1년 소멸·하트 전환 먼저(상품권은 본인인증·세무 확인 뒤)·독점 100일 고정·외부 제작자는 서버 원장·심사 뒤·규칙은 별도 '제작자 약관'으로. 서버 조립 뒤 BYOK는 관리자·개발용으로만: 6장). **플레이 가이드**(work.js guide — 제작자가 독자에게 주는 안내문, AI에는 보내지 않음): guideHTML(상세 페이지 소개 아래·도감 작품 칸, 없으면 숨김)·guideSheet(대화방 드로어 main의 '플레이 가이드' — 최신 작품에서 읽음), 모두 esc + pre-wrap. 예시는 m/godseats.
