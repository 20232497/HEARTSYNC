## 출시 전 할 일
compliance.md 8장의 순서를 따르고, 아래는 문서들이 약속했지만 코드·설정에 아직 없는 것을 한데 모은 목록이에요.

### 사업·계약(코드 밖)
- [ ] 사업자등록 → 통신판매업 신고 → PG(PortOne) 가맹·본인인증 계약
- [ ] 전화번호·사업장 주소(바닥글에 공개됨) 마련
- [ ] Anthropic 콘솔 월 지출 한도, Supabase 유료 요금제(백업), 운영 계정 전부 2단계 인증
- [ ] 변호사 검토(compliance.md 10장 질문 9개), 세무사 상담(업종·과세 유형)

### 막히는 것(보안 H)
- [ ] **서버 장부**: 하트·무료 턴·PLUS를 서버가 세고, PortOne 웹훅 서명을 확인해 지급(H1)
- [ ] **무료 길 남용 방지**: 등급별 입력 길이 상한, 토큰 예산, 서버가 센 무료 턴, 새 계정 제한(H2)

### 가입·계정
- [ ] 가입·첫 소셜 로그인 동의 단계: 출생연도, 만 14세 확인, 약관 동의(버전·일시 기록), 선택 마케팅([ui-copy.md](ui-copy.md) §2)
- [ ] 계정에 `birth_year`·`teen`(서버가 판단), 약관 바뀜 안내와 거부 시 전액 환불 흐름
- [ ] MY → 알림(제재·이의제기), MY → 결제 관리·결제 내역·하트 내역

### 결제
- [ ] 결제 전 고지 요약, 결제 완료 화면·영수증 메일(§3)
- [ ] ‘무제한’ 문구 정리(§3 표 — store·pay·faq·model-sheet·room-drawer·chat/view)
- [ ] PLUS 해지 버튼(일반·중도), 청약철회·환불 요청 흐름, 정기결제 가격 변경 동의(§5, 약관 제22~24조)
- [ ] 실패한 턴 자동 환원(서버 장부 기준), 하트 유효기간·만료 30일 전 알림
- [ ] 첫 결제 본인인증, 미성년 보호자 동의·한도·결제 알림(§4) — 본인인증 응답에서 이름·전화번호는 보관하지 않음
- [ ] 권유 창 ‘7일간 보지 않기’, 버튼 무게 맞추기(§5)

### 청소년·콘텐츠 — 만 14세 이상으로 열므로 출시 전 필수
Anthropic 지침을 지키지 않으면 회사 키 계정이 정지될 수 있어요(서비스 전체가 멈춤). 아래와 AI 칸의 배지·첫 대화 안내가 출시 조건이에요.
- [ ] 청소년 지시문을 서버 관문에서 계정의 teen 여부로 붙이기
- [ ] 대화 속 나이 신호 안내(`minorHint` 재사용, 차단 아님), 60분·심야 알림, 개인정보 입력 안내
- [ ] 신고: 메시지 신고와 등급에 맞춘 사유 일곱 가지는 있음(feat/frame-3) — 남은 것은 작품 신고, 지워도 남는 처리 기록, 제재 기록 표, 이의제기 화면(§8, operation-policy.md)
- [ ] 자동 검사·신고 횟수 주간 집계(내용 없이 횟수만)
- [ ] ‘안전하게 이용하기’ 페이지(youth-protection.md §6)

### AI
- [ ] ‘AI 캐릭터’ 배지, 말풍선 `aria-label`, 첫 대화 안내(계정에 한 번), 내보내기 머리말(§6)
- [ ] 위기 신호 감지(서버) + 위기 안내 카드(§7)
- [ ] `rulesPrompt`에 세 규칙: AI임을 부정하지 않기, 자해·자살 조장 금지와 도움 권하기, 고립·의존 유도 금지(ai-policy.md 6-4)

### 데이터·보안(M·L)
- [ ] 관리자 MFA(`aal2`), 저장 용량 남용 방지, 보안 헤더·CSP(`_headers`), 관리자 도구를 출시 배포에서 빼기(M1~M3, M6)
- [ ] 결제·동의·분쟁 기록을 계정 삭제와 분리 보관, 보관 기간 지나면 자동 파기(pg_cron)(M4, privacy.md 3항)
- [ ] `admin_audit` 표(관리자 접속 기록 1년 이상)(M5)
- [ ] 요청 접속 기록 3개월, `chat_usage` 1년 파기, 대화 관문 CORS를 운영 도메인으로, `safety.js` 고정(L1~L5)
- [ ] `/.well-known/security.txt`, GitHub 비밀 검사 켜기(internal-plan.md 11·16장)
