# 화면 문구 — 출시판 초안

> 약관·방침·법령이 화면에 요구하는 문구를 한곳에 모았어요. 개발할 때 이 문구를 그대로 쓰고, 바꿀 때는 약관 조항과 같이 고쳐요. 【 】는 출시 전에 채울 값, ⚖️는 변호사 확인, 🔎는 출시 직전 재확인이에요.
> 근거 조문은 [compliance.md](compliance.md)의 표에 있어요.

## §1 사업자 정보 바닥글
**근거**: 전자상거래법 제10조①(사이버몰 운영자 표시), 제13조①(신원 정보) 👁
**위치**: 홈 맨 아래, MY 맨 아래, 로그인 화면 맨 아래, 약관·방침 등 문서 페이지 바닥. 접어 두되(‘사업자 정보 ▾’) 한 번 누르면 모두 보이게.

```
HEART SYNC
상호 【상호】 · 대표 【이름】
주소 【사업장 주소】
사업자등록번호 【000-00-00000】 사업자 정보 확인 ↗
통신판매업 신고번호 【제0000-서울○○-0000호】
전화 【000-0000-0000】 · 이메일 heartsyncchat@gmail.com
호스팅 제공자 Cloudflare, Inc. · Supabase, Inc.
이용약관 · 개인정보처리방침(굵게) · 청소년 보호 정책 · 운영정책 · AI 이용 안내
```
- '사업자 정보 확인'은 공정위 사업자 정보 공개 페이지(ftc.go.kr의 통신판매업자 조회)로 연결 🔎
- '개인정보처리방침'은 다른 링크와 구분되게 굵게(개인정보 보호법 시행령 제31조③ 🔎)
- 전화는 실제로 받는 번호. 집 주소·개인 휴대폰을 쓰기 싫으면 비상주 사무실·업무용 번호를 먼저 마련(사업자등록 때 정함)

## §2 가입·첫 로그인 동의
**근거**: 약관 동의(전자상거래법), 개인정보는 계약 이행이라 **동의가 아닌 고지**(개인정보 보호법 제15조①4), 만 14세 확인(제22조의2), 광고 수신 선택 동의(정보통신망법 제50조), AI 사전 고지(인공지능 기본법 제31조①, 시행령 제23조①2)
**위치**: 이메일 가입 화면, 그리고 **소셜 로그인으로 처음 들어온 직후 한 번**(소셜은 가입 화면이 없으므로). 이 단계를 마쳐야 대화를 시작할 수 있어요. 기록: 동의 일시·약관 버전·출생연도·마케팅 선택을 계정에 저장.

```
HEART SYNC 시작하기

출생연도  [ 선택 ▾ ]
  만 14세 미만은 가입할 수 없어요.

[ ] (필수) 만 14세 이상입니다
[ ] (필수) 이용약관에 동의합니다  보기 ›
[ ] (선택) 이벤트·혜택 소식을 이메일로 받을게요
       언제든 MY → 알림에서 끌 수 있어요.

개인정보처리방침에 따라 서비스 제공에 필요한 정보를 처리해요.  보기 ›
HEART SYNC의 캐릭터 대화는 생성형 AI가 만들어요. 캐릭터는 실제 사람이 아니에요.  AI 이용 안내 ›

[ 모두 동의 ]      [ 시작하기 ]
```
- 체크 칸은 모두 **비어 있는 상태**로 시작(미리 체크 금지 — 다크패턴)
- '모두 동의'는 필수와 선택을 함께 체크하되, 누른 뒤 선택 항목을 따로 끌 수 있어야 해요
- 처리방침·AI 안내는 **체크 칸을 만들지 않아요**(동의가 아니라 고지). '필수 동의' 묶음에 넣으면 동의를 강제하는 것이 돼요
- 출생연도로 계산한 나이가 14세 미만이면 '시작하기'를 막고: `만 14세 미만은 HEART SYNC에 가입할 수 없어요.` 입력값은 저장하지 않아요
- 19세 미만이면 가입 직후 한 번: `만 19세 미만 회원에게는 청소년 보호 설정이 적용돼요. 결제하려면 보호자의 동의가 필요해요. 청소년 보호 정책 ›`
- 광고 메일을 보낼 때는 제목 앞에 `(광고)`, 본문 끝에 수신 거부 방법. 동의 2년마다 다시 확인(정보통신망법 시행령 🔎)

### 약관 바뀜 안내(약관 제3조)
```
이용약관이 바뀌어요 (【YYYY.MM.DD】부터)
• 【바뀌는 점 1】
• 【바뀌는 점 2】
바뀐 약관에 동의하지 않으면 시행일 전까지 탈퇴할 수 있고, 남은 유료 하트와 PLUS 남은 기간은 공제 없이 돌려드려요.
[ 전문 보기 ]  [ 확인 ]
```

## §3 결제 전 고지
**근거**: 전자상거래법 제13조②(거래 조건), 제17조②5·⑥(디지털콘텐츠 철회 제한은 미리 알리고 시험 사용을 줘야 함), 시행령 제21조의2, 표시·광고법(‘무제한’) 🔎
**위치**: 결제 버튼이 있는 시트. 아래 요약이 결제 버튼 **바로 위**에 보여야 하고(접어 두지 않음), ‘자세히’로 약관 제5장을 엶.

### 하트 묶음
```
하트 300개 + 보너스 30개
4,900원 (부가세 포함) · 결제 즉시 지급

• 하트는 HEART SYNC 안에서만 쓸 수 있고, 양도·현금 교환은 안 돼요.
• 유효기간: 유료 하트 5년, 보너스 하트 1년
• 7일 안에는 쓰지 않은 하트만큼 청약철회할 수 있어요. 하트를 써서 이미 받은 AI 응답은 철회할 수 없어요.
• 7일이 지나면 남은 유료 하트를 10%를 뺀 금액으로 환불받을 수 있어요.
• 결제 전에 매일 무료 【10】턴(라이트)으로 미리 써 볼 수 있어요.
판매자 【상호】 · 환불·청약철회 안내 › · 이용약관 ›

[ 4,900원 결제하기 ]
```

### PLUS
```
HEART SYNC+ (PLUS)
월 9,900원 (부가세 포함) · 오늘 결제, 매월 【DD】일 자동 결제

• 라이트 모델 하루 【N】턴까지 하트 없이
• 스토리·마스터 모델 하트 50% 할인
• 매달 하트 300개 (지급일부터 90일)
• 장기기억 【10,000】자 · 기억력 【N】턴 · 대화방 【N】개
• 언제든 MY → 결제 관리에서 해지할 수 있어요.
   - 일반 해지: 다음 결제부터 멈추고, 남은 기간은 그대로 써요.
   - 중도 해지: 바로 끝내고, 쓴 날과 쓴 PLUS 하트만큼 빼고 돌려드려요.
• 7일 안에 PLUS 혜택을 쓰지 않았다면 전액 돌려드려요.
• 가격이 오르면 30일 전에 알리고 동의를 받아요. 동의하지 않으면 자동 결제가 멈춰요.
판매자 【상호】 · 환불·청약철회 안내 › · 이용약관 ›

[ 월 9,900원 정기결제 시작 ]
```

## §4 미성년 결제·보호자 동의
**근거**: 민법 제5조, 전자상거래법 제13조③(미성년자 취소권 고지) 👁, 약관 제21조
**위치**: 본인인증 결과가 만 19세 미만일 때 결제 시트 대신.

### 청소년 회원 화면
```
보호자 동의가 필요해요
만 19세 미만은 보호자(법정대리인)가 동의해야 결제할 수 있어요.
보호자가 본인인증을 하고, 한 달 결제 한도를 정해요.

[ 보호자에게 동의 요청 보내기 ]   [ 나중에 ]

보호자가 동의하지 않은 미성년자의 결제는 미성년자 본인이나 보호자가 취소할 수 있어요.
```

### 보호자 동의 화면(보호자가 링크로 엶)
```
【닉네임】 님의 HEART SYNC 결제 동의
HEART SYNC는 AI 캐릭터와 이야기를 나누는 서비스예요. 모든 작품은 전체이용가로 운영돼요.

1. 보호자 본인인증  [ 휴대폰 인증 ]
2. 자녀와의 관계   ( ) 부모  ( ) 그 밖의 법정대리인
3. 한 달 결제 한도  [ 1만 ▾ ] 원 (최대 【7만】 원)
4. [ ] 자녀의 결제에 동의합니다. 결제할 때마다 알림을 받습니다.

• 언제든 동의를 철회하거나 한도를 바꿀 수 있어요: 이 링크 또는 heartsyncchat@gmail.com
• 동의 없이 이뤄진 미성년자의 결제는 보호자나 자녀가 취소할 수 있어요.
• 결제 상품, 청약철회, 환불 조건: 이용약관 제5장 ›

[ 동의하기 ]   [ 동의하지 않기 ]
```
- 관계 확인 방법(자기 진술 + 본인인증 이름 대조로 충분한지, 서류가 필요한지) ⚖️
- 보호자 알림: `[HEART SYNC] 【닉네임】 님이 【상품】 【금액】원을 결제했어요. 이번 달 【누적】/【한도】원. 취소·한도 변경 › `

## §5 다크패턴 없애기
**근거**: 전자상거래법 제21조의2①(2025-02-14 시행), 시행령 제27조의2 👁, 공정위 가이드라인 🔎

| 할 일 | 지금 | 바꿀 것 |
|---|---|---|
| **해지를 가입만큼 쉽게** | MY에 PLUS 해지가 없음 | MY → 결제 관리 → `PLUS 해지` 버튼. 가입과 같은 단계 수(누르기 → 확인 시트 → 끝). 확인 시트에 일반/중도 해지 선택과 돌려받을 금액 미리 보기. 붙잡는 화면(혜택 다시 보여 주기)은 **한 번만**, ‘그래도 해지’ 버튼을 같은 크기로 |
| 같은 무게의 버튼 | 하트 부족 창 ‘♥n로 계속’(pri)과 ‘그만하기’(ghost) | 거절 버튼도 읽기 쉬운 크기·대비로. 색 강조는 하나만 두되 거절을 숨기지 않기 |
| 반복 권유 | 하트 부족·PLUS 권유 창이 매번 뜸 | 권유 창에 `7일간 보지 않기`. 누르면 7일 동안 같은 권유를 띄우지 않기(하트가 실제로 모자라 보낼 수 없을 때의 안내는 예외) |
| 미리 체크 금지 | — | 마케팅 동의, 자동 충전 같은 선택은 늘 꺼진 상태로 시작 |
| 총액 표시 | 하트 수만 보임 | 스토어 카드에 원화 총액(부가세 포함)을 먼저, 하트당 가격은 작게 |
| 정기결제 표시 | ‘/ 월 · 언제든 해지’ | 결제 버튼에 ‘정기결제’를 적고, 다음 결제일을 같은 화면에 |
| 할인 표시 | — | ‘50% 할인’은 기준 가격(정가)을 같이 보이기(이미 취소선으로 보임). 기간 한정 할인은 끝나는 날짜를 |

### PLUS 해지 확인 시트
```
PLUS를 해지할까요?
( ) 일반 해지 — 【YYYY.MM.DD】까지 PLUS를 쓰고, 그 뒤 자동 결제가 멈춰요.
( ) 중도 해지 — 지금 바로 끝내고 【n,nnn】원을 돌려드려요.
     (9,900원 − 쓴 【n】일 × 하루 값(9,900원 ÷ 이번 기간 【30】일) − 쓴 PLUS 하트 【n】개 × 19원)
[ 해지하기 ]   [ 그대로 쓰기 ]
```

## §6 AI 표시·첫 대화 안내
**근거**: 인공지능 기본법 제31조①②, 시행령 제23조 👁, [ai-policy.md](ai-policy.md) 6-1

| 자리 | 문구 |
|---|---|
| 대화 화면 머리(늘) | 배지 `AI 캐릭터` |
| AI 말풍선 `aria-label` | `AI 응답: 【캐릭터 이름】` |
| 작품에서 첫 대화를 시작하기 전(작품마다 한 번이 아니라 계정에 한 번) | `캐릭터의 답은 생성형 AI가 만들어요. 작품 설정에 따른 허구이고, 틀리거나 이상한 답을 할 수 있어요. 진지하게 물으면 캐릭터는 자기가 AI라는 걸 숨기지 않아요.` [ 알겠어요 ] |

**위치**: 서버가 위기 신호 플래그를 붙인 응답의 **위**. 닫을 수 있고, 대화는 이어 갈 수 있어요. 일반 회원과 청소년 회원 문구를 나눠요.

```
혹시 많이 힘드신가요?
혼자 견디지 않아도 돼요. 지금 바로 이야기할 수 있는 곳이 있어요.
📞 자살예방상담전화 109 (24시간)
📞 정신건강위기상담전화 1577-0199
🚨 위급하면 112 · 119
[ 닫기 ]
```
청소년 회원은 둘째 줄 아래에 `💬 청소년상담 1388 (전화·문자·카카오톡 #1388)`을 먼저 둬요.

## §8 신고·제재 안내
**근거**: [operation-policy.md](operation-policy.md), 약관 제15·16조

**메시지 신고는 이미 있어요**(`src/js/ui/report.js` — AI 말풍선 메뉴 `신고` → 사유 · 덧붙일 말(선택) · `이 메시지 앞부분(300자)을 함께 보내기`(기본 켜짐, 끄면 사유와 작품 이름만) → 문의 표에 ‘신고’ 분류로 접수, 답은 ‘내 문의’). 처리방침 2026-11-23 시행본에 반영돼 있어요. 사유는 운영정책 등급에 맞춘 일곱 가지예요: `미성년자 관련 성적 내용 · 자해·자살 조장 · 혐오·괴롭힘 · 불법 정보 · 개인정보 노출 · 오류·이상한 응답 · 기타`. 앞의 둘은 '우선'으로 관리자 목록 맨 위에 따로 보여요(`src/js/services/support.js` REPORT_REASONS·urgentReport). 출시 전에 더할 것:
- 작품 상세 ⋯ → `신고하기`(사유 + 덧붙일 말)
- 접수 뒤 문구는 지금 것 그대로: `신고를 접수했어요. 답변은 고객센터의 '내 문의'에서 볼 수 있어요`
- 신고한 회원이 ‘내 문의’에서 신고를 지워도 운영자 쪽 처리 기록은 남기기(처리방침 3항 보관 기간)
- 제재 알림: `【날짜】 운영정책 【조항】 위반으로 【조치】가 적용됐어요. 사유: 【요약】. 14일 안에 이의를 신청할 수 있어요. [이의 신청]`
