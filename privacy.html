HEART SYNC앱으로 돌아가기

개인정보처리방침

시행일 2026년 11월 23일 · 이전 방침

변경 안내: 이 방침은 2026년 11월 23일부터 적용되며, 그 전까지는 2026년 11월 5일 시행본이 적용됩니다(11월 13일·11월 16일에 시행하려던 안은 시행 전에 이 안으로 합쳐졌습니다). 새로 더한 내용: 로그인한 경우 찜한 작품·최근 본 작품·도감에 모은 그림 기록을 2026년 11월 23일부터 계정에도 저장합니다(그 전에는 이 기기에만 둡니다). 대화방의 ‘신고’로 보낸 내용(사유, 작품 이름, 끄지 않았다면 신고한 메시지의 앞부분 300자)을 고객센터 문의와 같이 다룹니다. 서비스를 정리하면서 처리하는 개인정보가 줄어든 내용을 반영했습니다: AI 대화는 Anthropic으로만 보내고 OpenRouter로 보내지 않습니다. 이용자가 그림을 만드는 기능과 Runware 전송을 없앴습니다. API 키는 계정에 저장하지 않습니다. 성인 모드·휴대폰 성인 인증·작품 만들기와 공개를 제공하지 않습니다. 예전 기능으로 계정에 남은 데이터를 어떻게 다루는지 적었습니다.

HEART SYNC(이하 ‘서비스’)는 캐릭터와 대화하며 이야기를 만들어 가는 웹 앱으로, 개인 개발자(이하 ‘운영자’)가 운영합니다. 운영자는 「개인정보 보호법」 등 관련 법령을 지키며, 이 방침으로 어떤 개인정보를 왜 처리하고 어떻게 보호하는지 알려 드립니다.

한눈에 보기
  • 로그인하지 않고 쓰면 대화·페르소나·설정은 이 기기(브라우저)에만 저장되고 운영자에게 오지 않습니다.
  • 로그인하면 계정 정보와 앱 데이터를 Supabase(아일랜드 데이터센터)에 저장해 여러 기기에서 이어 쓸 수 있게 합니다.
  • AI 대화는 이용자가 직접 넣은 API 키로 이용자의 브라우저에서 AI 회사(Anthropic)로 바로 전송됩니다. 운영자 서버를 거치지 않습니다.
  • 대화 속 그림은 운영자가 미리 만들어 작품에 실은 것을 보여 드립니다. 이용자의 데이터는 그림 생성 서비스로 전송되지 않습니다.
  • API 키는 이 기기(브라우저)에만 저장하고 계정이나 운영자에게 보내지 않습니다.
  • 고객센터의 ‘문의하기’와 대화방의 ‘신고’로 남긴 내용은 답변을 위해 계정과 함께 저장되며, 운영자(관리자 계정)만 볼 수 있습니다. 신고에는 이용자가 끄지 않았다면 신고한 메시지의 앞부분 300자가 담깁니다(대화 전체는 보내지 않습니다).
  • 광고·분석 추적 도구를 쓰지 않고, 개인정보를 팔거나 다른 곳에 넘기지 않습니다.

1. 처리하는 개인정보 항목

서비스는 로그인 없이도 쓸 수 있습니다. 로그인(회원가입)하는 경우에만 아래 정보를 처리합니다.

가입·로그인 방식에 따라

  • 이메일로 가입: 이메일 주소, 비밀번호(Supabase가 복원할 수 없는 해시로 바꿔 저장하므로 운영자도 원문을 알 수 없습니다)
  • 카카오로 로그인: 카카오 회원 식별자, 닉네임, 프로필 사진·이메일 주소(카카오 로그인 때 제공에 동의한 경우에만, 선택)
  • 네이버로 로그인: 네이버 회원 식별자, 네이버에서 제공에 동의한 항목(별명 등)
  • Google로 로그인: Google 계정 식별자, 이메일 주소, 이름, 프로필 사진

서비스를 쓰면서 만들어지는 정보(로그인한 경우 계정에 저장)

  • 대화 내용과 대화 요약, 페르소나(이용자가 정한 ‘나’의 설정)
  • 이용자가 올린 페르소나 사진, 앱 설정(API 키는 빼고)
  • 찜한 작품, 최근 본 작품, 도감에 모은 그림 기록(대화에서 본 그림의 코드) — 2026년 11월 23일부터 계정에 저장합니다. 그 전에는 이 기기에만 두며, 그날 이후 로그인한 상태로 앱을 열면 이 기기에 쌓인 기록이 계정으로 올라가 다른 기기의 기록과 합쳐집니다.

예전 기능으로 계정에 저장된 데이터

  • 2026년 11월 정리 전의 기능으로 계정에 저장해 둔 데이터 — 직접 만든 작품·캐릭터와 크리에이터 이름, 서비스에서 만든 그림, 암호화된 API 키(‘API 키도 계정에 저장’을 켰던 경우)
  • 서비스는 이 데이터를 더 이상 읽거나 쓰지 않으며, 계정을 삭제할 때 함께 지웁니다. 그 전에 지우기를 원하면 12항의 이메일로 요청해 주세요.

고객센터 문의·메시지 신고(MY → 고객센터 → 문의하기, 대화방 말풍선의 ‘신고’ — 로그인한 경우에만)

  • 필수: 문의 분류, 제목, 내용, 작성 시각, 문의한 계정의 식별자
  • 선택: 답변 받을 이메일 주소(적은 경우), 앱·브라우저 정보(‘앱·브라우저 정보 함께 보내기’를 켠 경우 — 브라우저 종류(User-Agent), 화면 크기, AI 연결 방식, 접속한 주소)
  • 메시지 신고(대화방에서 AI 메시지의 ‘신고’를 누른 경우): 고른 사유, 작품 이름, 덧붙인 말(적은 경우), 신고한 메시지의 앞부분 300자(‘이 메시지 앞부분을 함께 보내기’를 끄지 않은 경우 — 보내기 전에 화면에서 내용을 확인하고 끌 수 있습니다). 대화 전체나 다른 메시지는 보내지 않습니다.
  • 운영자가 남긴 답변과 답변 시각

자동으로 생기는 정보

  • 로그인 시각, 접속 IP 주소, 브라우저 정보 등 Supabase가 보안과 장애 대응을 위해 남기는 접속 기록

실명, 전화번호, 주민등록번호, 결제 정보는 저장하지 않습니다(서비스 안의 결제는 실제로 청구되지 않는 시연입니다). 서비스는 지금 성인 모드와 휴대폰 성인 인증을 제공하지 않습니다. 대화나 페르소나에는 실제 개인정보를 적지 않기를 권합니다.

2. 처리 목적

  • 회원 식별, 로그인, 계정 관리
  • 대화·페르소나·설정과 찜·최근 본 작품·모은 그림 기록을 계정에 저장하고 PC와 휴대폰 등 여러 기기에서 이어 쓰기(동기화)
  • 가입 인증 메일과 비밀번호 재설정 메일 발송
  • 문의·신고 접수와 답변, 신고한 내용의 확인과 조치, 오류 원인 확인(문의할 때 함께 보낸 앱·브라우저 정보와 신고에 담긴 메시지 일부는 이 목적에만 씁니다)
  • 부정 이용 방지, 보안, 오류 대응

위 목적 밖으로 쓰지 않으며, 광고·마케팅이나 이용자 성향 분석에 쓰지 않습니다. 목적이 바뀌면 미리 알리고 필요한 동의를 받겠습니다.

3. 보관 기간과 파기

  • 개인정보는 계정을 삭제할 때까지 보관합니다.
  • 고객센터 문의와 메시지 신고는 이용자가 ‘내 문의’에서 지우거나 계정을 삭제할 때까지 보관합니다. 계정을 삭제하면 문의·신고와 답변도 함께 지워집니다.
  • 앱의 MY → 계정 → 계정 삭제를 누르면 계정과 계정에 저장된 데이터가 즉시 모두 삭제됩니다.
  • 계정은 남기고 저장된 데이터만 지우려면 MY → 설정의 ‘모든 데이터 초기화’를 쓰면 됩니다. 로그아웃할 때 ‘이 기기 데이터도 지우기’를 고르면 이 기기에 남은 데이터도 지워집니다.
  • Supabase의 백업·로그에 남은 사본은 Supabase의 보관 주기에 따라 지워집니다.
  • 삭제는 복구할 수 없는 방법으로 합니다. 종이로 보관하는 개인정보는 없습니다.
  • 법령이 보존을 요구하는 정보가 생기면 그 기간만큼 따로 보관하고, 이 방침에 적겠습니다.

4. 제3자 제공

운영자는 이용자의 개인정보를 제3자에게 제공하지 않습니다. 다만 법령에 근거가 있거나 수사기관이 법령에 정한 절차에 따라 요청하는 경우는 예외입니다.

5. 처리 위탁과 국외 이전

서비스는 아래 회사의 기능을 쓰며, 이 과정에서 개인정보가 국외로 전송됩니다. 모든 전송은 암호화된 통신(HTTPS)으로 이뤄집니다.

6. Google 로그인으로 받는 정보

  • Google 로그인은 기본 범위(openid, 이메일, 프로필)만 요청해 Google 계정 식별자, 이메일 주소, 이름, 프로필 사진을 받습니다. Gmail, Google 드라이브, 연락처 등 다른 Google 데이터에는 접근하지 않습니다.
  • 받은 정보는 로그인, 계정 식별, 앱 안의 계정 표시에만 씁니다. 광고, 판매, AI 모델 학습에 쓰지 않고, 5항의 Supabase 저장 말고는 다른 곳에 넘기지 않습니다.
  • HEART SYNC가 Google API에서 받은 정보를 쓰고 전송하는 방식은 제한적 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.
  • Google 계정의 서드 파티 앱 및 서비스 연결에서 HEART SYNC 연결을 끊을 수 있습니다. 저장된 데이터까지 지우려면 앱에서 계정을 삭제해 주세요.

7. API 키 보호

  • 이용자가 넣은 API 키(Anthropic)는 이 기기(브라우저)에만 저장되며, 로그인해도 계정이나 운영자에게 보내지 않습니다. 그래서 다른 기기에서는 키를 한 번 더 넣어야 합니다.
  • 키는 이용자의 브라우저에서 Anthropic으로 요청할 때만 쓰입니다. 이 기기에서 지우려면 MY → AI 연결에서 키 칸을 비우고 저장하면 됩니다. 브라우저 설정에서 이 사이트의 데이터를 지우거나, 로그아웃할 때 ‘이 기기 데이터도 지우기’를 고르면 예전에 넣어 둔 키까지 모두 지워집니다.
  • 예전에 ‘API 키도 계정에 저장’을 켰던 경우 계정에 남은 암호문(이 기기에서 잠근 것이라 운영자도 볼 수 없음)과, 예전에 넣어 둔 OpenRouter·Runware 키는 서비스가 더 이상 쓰지 않습니다. 계정의 암호문은 1항대로 계정 삭제 때 지워지고, Runware·OpenRouter에 등록된 키 자체를 폐기하려면 각 회사 사이트에서 해야 합니다.

8. 안전성 확보 조치

  • 모든 통신을 HTTPS로 암호화합니다.
  • 데이터베이스에 행 수준 보안(RLS)을 걸어 로그인한 본인의 데이터만 읽고 쓸 수 있게 합니다. 고객센터 문의는 쓴 본인과, 데이터베이스에 관리자로 등록된 운영자 계정만 볼 수 있습니다.
  • 비밀번호는 해시로 저장하고, API 키는 서버에 저장하지 않습니다.
  • 관리용 비밀 키는 앱과 공개 저장소에 넣지 않고, 관리 화면은 운영자만 접근합니다.

9. 브라우저 저장소와 쿠키

  • 서비스는 광고·분석용 쿠키나 추적 도구를 쓰지 않습니다.
  • 로그인 상태, 설정, 대화, 페르소나 사진, API 키는 브라우저 저장소(localStorage·IndexedDB)에 저장되며 이 기기 안에만 있습니다. 브라우저 설정에서 이 사이트의 데이터를 지우면 삭제됩니다. 로그인하지 않고 쓴 데이터는 지우면 되살릴 수 없습니다.
  • Supabase 앞단의 보안 서비스(Cloudflare)가 자동화된 공격을 막기 위해 보안 쿠키를 둘 수 있습니다.
