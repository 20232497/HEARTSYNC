# 남성향 애니 화풍 (보관본)

남성향 작품의 인물 그림에 쓰는 화풍(`manime`)입니다. 앱은 그림을 만들지 않으므로, 관리자가 앱 밖에서 이 값으로 그림을 만들어 `content/<작품>/images/`에 넣습니다.

- **v9(2026-11-19)** — 가볍고 만화 같던 v8을 **반실사 만화(웹소설 표지) 마감**으로 바꿨습니다. 사용자가 고른 정면 인물 견본(`samples/`)이 기준입니다. 모델·크기·칸·인물 규칙(앞머리·옷·나이대·장소)은 v8 그대로이고 마감·빛·얼굴·기본 표정·구도·후처리가 바뀌었습니다(아래 'v9에서 바뀐 것'). v8 값은 git 기록에 있습니다.
- v8(2026-11-13) — 2026-11-12에 예전 값(v7, Animagine XL 4.0)을 비우고 처음부터 다시 정했습니다. 사용자와 비교 생성을 거듭하며 묻고 답해 정한 값입니다. 예전 값은 git 기록(커밋 `180fcb7`)에 있습니다.
- **인물마다 따로 손대지 않습니다.** 작품 데이터(`cast[]`의 tags·look·temper·age, `places[]`의 tags)를 칸에 끼워 프롬프트를 만듭니다. 그림이 이상하면 화풍을 인물에 맞추지 말고 **작품 태그를 구체적으로** 고칩니다(아래 '작품 태그에 바라는 것').
- 아직 본 생성 전입니다 — 인물마다 시드 하나로만 확인했습니다('남은 일').

## 그림 두 가지

| | 프로필(칸 0) | 감정 그림(칸 1~14) |
| --- | --- | --- |
| 구도 | 얼굴이 화면을 채움 `(close-up:1.0), (portrait:1.2), (head tilt:0.8), (facing viewer:1.0)` | 가슴까지, 서 있음 `(standing:1.0), (upper body:1.1), (head tilt:0.5), (facing viewer:1.0)` — 둘 다 정면 |
| 배경 | 어두운 단색(인물의 머리·옷 색이 비침) | 작품의 장소 |
| 인물 태그 | 하의 낱말을 뺌(안 보이는데 색이 윗옷에 번짐) · 무기는 그대로 | 공격 칸(12) 말고는 무기 낱말을 뺌(손은 손동작에) · 속옷 층 규칙 |

**조립 순서:** 인원·성인 → 인물 → 표정·손동작 → 구도 → (장소) → 얼굴 → 몸 → 마감 → 조명·배경 → 품질.

## 규칙

**인물 칸** — 작품 태그 그대로 ×1.1, 눈색 ×1.0(눈매 낱말은 ×1.1), 수염 ×0.7. 팔·손·등에 붙는 낱말(`… on forearm` 등)과 `sleeves rolled up`은 뺍니다(얼굴로 옮겨 붙음). 모든 인물에 `(messy hair:0.7), (floating hair:0.4)`(풍성하고 흐트러진 머리).

- **앞머리**: 태그에 `forehead`가 있으면 이마를 두고 가운데 가르마. 이미 앞머리(blunt·curtain bangs 등)가 있으면 그대로. 그 밖은 옆으로 넘긴 앞머리 태그를 빼고 — 여성은 눈을 덮는 앞머리 `(blunt bangs:1.0), (long bangs:0.9), (eyes visible through hair:1.1)`, 남성은 시스루 앞머리, 서른 넘은 남성은 자연스러운 가르마.
- **옷**: 겉옷만 적혀 있으면 `(shirt:1.1)`. 감정 그림은 정장·카디건인데 셔츠가 없으면 `white shirt`, 겹옷깃 옷(한푸·도복·로브)인데 속옷이 없으면 `white undershirt`. 태그에 `long cloak`·`long cape`가 있으면 짧은 망토를 네거티브로 막음.
- **남성**: 머리 길이 낱말이 없으면 `short hair`. 네거티브에 긴 머리.

**여성 얼굴** — 공통 문구(속눈썹·옅은 눈꼬리 선·또렷한 홍채·옅은 홍조·윤기 입술·콧대·고운 이목구비) + **눈매 규칙**: 작품 태그의 눈매 낱말로 눈 모양을 정합니다.

| 태그 | 눈 |
| --- | --- |
| droopy eyes | `(tareme:0.8), (half-closed eyes:0.5)` |
| round eyes | `(half-closed eyes:0.2)` |
| upturned eyes | `(half-closed eyes:0.7), (tsurime:0.4)` |
| narrow eyes | `(half-closed eyes:0.8), (jitome:0.4)` |
| sharp eyes | `(half-closed eyes:0.6), (tsurime:0.3)` |
| (없음) | `(half-closed eyes:0.6)` |

몸은 `slender, (slim:1.1~1.2)` — 가녀리게. 감정 그림에서 소매 길이를 적지 않은 옷은 `(long sleeves:1.2)`. 큰 가슴·굴곡 과장·드러난 어깨와 팔은 네거티브로 막습니다.

**남성의 비율(감정 그림)** — 어깨가 넓고 머리가 작게(류건이 기준). 태그에 `broad shoulders`가 없는 인물에게 `(broad shoulders:1.1)`을 붙이고, 네거티브에 `(large head:1.3), (narrow shoulders:1.2)`. 구도는 여성과 같은 정면 구도입니다 — 아래에서 올려다보는 구도와 `athletic`은 그려 보고 쓰지 않기로 했습니다(겉옷이 벗겨지고 근육이 드러남). 프로필은 얼굴 구도라 그대로입니다.

**남성 얼굴** — 고운 미남(`(bishounen:1.0)`, 홍조·입술 문구 없음). **나이대**: 겉보기 나이(`cast[].age`, 없으면 look 글의 'N세')가 30 이상이면 잘생긴 아저씨 — `(mature male:0.5)`(서른 아래는 0.4), `(broad shoulders:0.5)`, 턱선 0.7, 속눈썹 문구 없음, 앞머리 대신 가르마. 태그에 `stubble` 같은 수염 낱말이 있으면 수염 네거티브를 빼고 긴 수염·콧수염만 막습니다.

**성격 → 기본 표정·손동작(칸 0·1)** — 여덟 가지: 도도 · 장난 · 해맑음 · 수줍음 · 다정 · 냉소 · 곧음 · 차가움. 작품의 `cast[].temper` 값 그대로 고릅니다. **v9부터 표정은 성격마다 다르지 않습니다** — 여자는 살짝 미소 지은 채 눈을 가늘게, 남자는 웃지 않고 입술을 다문 채 내려다보고(도도·냉소·곧음·차가움), 장난·해맑음·수줍음·다정인 남자는 눈을 갸름하게 뜨고 부드러운 눈길. 성격은 이 두 갈래와 여자의 손동작만 가릅니다(값이 없어도 같은 기본 표정). 안경·부채가 있으면 그 손동작이 먼저. 남성은 손동작 없이 표정만.

**성격별 표정(대표 칸)** — 대화에서 가장 자주 쓰이는 칸 2 웃음·3 부끄러움·4 슬픔·5 놀람·6 분노·7 삐침·8 공포·14 설렘은 표정과 손동작이 **성격마다 다릅니다**(`code/expressions.js`의 `TEMPER_EMO`). 도도한 인물은 입을 다문 채 웃고 부끄러우면 팔짱을 끼며 토라지고, 해맑은 인물은 활짝 웃고 두 볼을 감싸는 식입니다. 한 칸의 값은 여·남 표정 태그와, 필요하면 시선(피함·떨굼)과 눈 모양입니다. 만화 기호와 그 칸의 네거티브는 공통 표(`EMOTIONS`)의 것이 그대로 붙습니다. 성격 값이 없는 인물과 나머지 칸(9 부상·10 회복·11 휴식·12 공격·13 각성)은 공통 표정입니다. 성격이 같으면 태그도 같습니다.

**대표 인물의 버릇·소품** — 작품마다 대표 인물 한 명(표지의 주인공)은 몇몇 칸을 그 인물만의 버릇·소품으로 따로 씁니다(`LEAD_EMO`, 키는 `인물코드:이름`). 윤해라는 귀 뒤로 머리를 넘기고, 백연은 찻잔을 든 채 눈을 가늘게 뜨고 웃고, 차사현은 회중시계를 내려다보는 식입니다. 적힌 칸만 대신하고 나머지는 성격별 표를 따릅니다. 소품은 무기가 아닌 것만 씁니다(무기 낱말은 공격 칸 말고는 빠짐). 남자의 놀람·공포 칸은 눈을 덜 뜨고 둥근 눈·얼굴 클로즈업을 네거티브로 막습니다 — 크게 뜬 둥근 눈은 성인 남자를 앳돼 보이게 합니다. 소매 길이를 적지 않은 옷은 여·남 모두 긴소매로 그립니다(조끼 차림이 소매 없는 옷으로 그려지는 것을 막음).

**장소 칸(감정 그림)** — 작품의 장소 태그 ×1.1, 인물·구도 다음, 화풍 문구보다 앞. 사람·클로즈업 낱말과 기차(`steam locomotive` 등)는 뺍니다. 시간 낱말이 없으면 밤. 밤·저녁이면 어둑한 조명과 낮 네거티브, 낮이면 어둑한 조명을 뺍니다 — **시간대는 작품 태그가 정합니다.**

**감정 칸 2~14** — 구도와 옷은 그대로 두고 표정·손동작·만화 기호만 바꿉니다. 인물마다 시드를 하나로 고정합니다(`seedOf`).

## 꼭 지킬 것

- 긍정에 성인 표시 `(adult woman:1.2)` / `(adult man:1.3)`, 네거티브에 미성년 금지(`child, loli, shota, underage, toddler, aged down, baby face, young, teenager, chibi`)와 큰 머리·노출·달라붙는 옷을 **늘** 넣습니다. `assertSafe()`가 빠졌는지 검사합니다 — 그리기 전에 부릅니다.
- 눈을 덮는 앞머리와 홍조는 얼굴을 앳돼 보이게 합니다. **그린 뒤 눈으로 확인**하고, 어려 보이거나 노출이 있는 그림은 쓰지 않습니다.
- 위에서 내려다보며 몸을 숙이는 구도, `glossy`, `leaning forward`는 가슴골과 비치는 옷을 부릅니다 — 넣지 않습니다.

## 작품 태그에 바라는 것

- **옷을 구체적으로**: 속에 입는 옷과 하의의 색, 겉옷의 색·소매. 모호하면 칸마다 옷이 바뀝니다(`firefighter jacket` → 재킷·조끼·제복). 모델이 모르는 낱말(`scrubs`)은 풀어서.
- **옷깃 노출은 네거티브보다 옷 태그가 확실**합니다: `white collared shirt`, `black turtleneck dress`, `suit jacket`.
- **장소는 구체적인 사물로**: 비유 낱말은 엉뚱한 사물이 됩니다. 시간 낱말(`night`·`daytime`·`dusk` 등)을 적습니다.
- 서부식 `poncho`는 술·무늬가 달린 짧은 판초로 굳어 있습니다 — 길고 민무늬인 겉옷은 `hooded cloak, long cloak`.

## 겪은 일

- 모델보다 프롬프트·후처리의 영향이 큽니다. 색을 선명하게 하는 것은 프롬프트보다 후처리 채도가 확실합니다.
- 모든 인물에 같은 눈매를 입히면 다 날카롭고 비슷해집니다 — 눈매·성격으로 갈라야 인물마다 매력이 남습니다.
- `sleeping`은 잠옷·눕기를, `bandaged arm`은 걷은 소매를, 낯선 기호 낱말(`!`·`spoken heart`)은 밝은 배경을 부릅니다.
- 밝은 눈색의 남성은 `glowing eyes`에서 눈동자가 사라집니다 — 감정 그림은 `pupils`.
- 어두운 빛 문구와 만나면 옷 문구의 `ink`(먹빛)가 뺨의 얼룩이, `… on ear`가 뺨의 무늬가 됩니다 — 작품 태그에서 낱말을 바꾸는 쪽이 네거티브보다 확실합니다.
- 사람 없는 배경을 그릴 때 머리카락·피부 마감 문구(`FIN`)를 그대로 넣으면 사람 머리가 그려집니다 — 배경에는 칠·명암 문구만.
