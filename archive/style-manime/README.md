# 남성향 애니 화풍 (보관본)

남성향 작품 인물 그림에 쓰는 **애니(게임 일러스트) 화풍**(`manime`)입니다. 앱은 그림을 만들지 않으므로(2026-11-08 정리), 관리자가 앱 밖에서 이 값으로 그림을 만들어 `content/<작품>/images/`에 넣습니다. 남성향 일상(`archive/style-mdaily/`)과는 다른 화풍입니다.

- **v7(2026-11-11 확정)**: 사용자와 비교 생성 여러 라운드로 정함. **그림은 이 값으로 만듭니다.** v6(프로필·전신)에 감정 칸 규칙을 더한 판.
- 모델 하나, LoRA 없음. 그림 규격은 `tools/content-art.mjs`의 `ART_SPECS`(확정)와 같음 — 인물 프로필(0번 칸) 832×1248, 감정 칸(1~14) 1024×1024.

## 프롬프트 조립(v6)

**긍정:** 인원·성인(`1girl, solo, (adult woman:1.1)` / `1boy, solo, (adult man:1.2), (mature male:1.15)`) → 수위(`safe`) → 인물 태그 → 소품 → 장면·표정 → 배경 → (남자 짧은 머리) → 화풍 문구 → 품질(맨 끝)

- 인물 태그는 모두 1.15. **머리색·묶은 머리·눈색은 1.3**(눈매 태그 sharp·narrow·round·droopy·upturned eyes는 1.15 그대로).
- **눈색**은 작품의 영문 `tags`에 있습니다(2026-11-11에 25명 모두 넣음). 전에는 태그에 눈색이 없어 그림마다 바뀌었습니다.
- 장면 태그는 `manime.json`의 `sceneTags`(칸 0~14). 0번은 가슴 위, 1~14는 감정 칸(아래 '감정 칸').
- 배경은 검은 바탕 + 반짝임 + 역광 `(backlighting:0.9)` — 작품 장소는 넣지 않습니다(`bg.default`).
- **번개는 칸 0(프로필)에만**: 배경에 `(lightning:0.8), electricity`(`bg.profile`, 2026-11-11 사용자 결정). 번개가 인물 눈색을 따라가 인물마다 다른 기운처럼 보입니다. 감정 칸 1~14와 전신에는 넣지 않습니다(대화 속에 계속 나와 번잡하고, 전신에서는 옷이 바뀐 일이 있었음). 13번(각성) 칸은 장면 태그에 원래 번개가 있습니다.

**칸 0(프로필)에만 붙는 규칙**
- **표정**: 인물별 표정(`charm.expr` — 한글 외형 글의 표정: 홍레나 오만, 미소 해맑은 웃음, 당소소 윙크, 묵란 냉소, 화린 크게 웃음 등)이 있으면 그것, 없으면 눈매 규칙(sharp·narrow·upturned → 비웃는 미소, round·droopy → 웃음, 그 밖 옅은 미소). 같은 미소만 반복되지 않게.
- **소품**: `charm.prop`(윤채이 텀블러·백여울 부적·윤도경 술병) — 외형 글에 있는데 태그에 없던 것. 감정 칸과 전신에도 들어감(휴식 칸 11만 뺌).
- **높은 포니테일**(한서윤·남궁설·윤해라): `(from side:0.6), (hair over shoulder:1.2)` — 정면에서는 묶은 머리가 안 보임.
- **여성 인물**: 위에서 내려다본 각도 `(from above:0.6)` — 턱이 짧아 보임.

**여성 인물의 화장**: 화풍 문구에 `(blush:0.6), (nose blush:0.5), pink lips`, 아랫속눈썹 태그는 빼고, 네거티브에 `eyeshadow, (eyeliner:1.1)` — 진한 눈 화장 대신 옅게. 남성 인물은 화장 문구가 없습니다.

**부정:** 품질 네거티브 → 미성년 금지(`child, loli, shota, underage, toddler, aged down` — 늘 넣음) → 수위·노출 → 화풍 네거티브 → 성인 인상(여성 `baby face, round face, chibi` / 남성 가중 1.2·1.1) → 피부 → 그늘진 얼굴·빈 눈 → 눈 화장 → **머리 번짐 막기** `(multicolored hair:1.2), streaked hair, colored inner hair, gradient hair`

- 장면 태그가 부르는 낱말(3·14번 칸의 blush 등)은 네거티브에서 뺍니다.
- 머리 번짐 막기: 보라·청록 눈색이 검은 머리에 브릿지처럼 번졌습니다(눈색 가중을 1.2로 낮춰도 같음). 투톤 머리 인물이 생기면 그 인물만 뺄 것.

## 감정 칸 1~14(`emotion` — v7)

정사각 1024×1024, **머리~허벅지** `(cowboy shot:1.2)`에 칸마다 **몸짓** — 표정만이 아니라 몸으로 감정이 읽히게(2026-11-11 사용자 결정, 2:3과 비교해 정사각).

| 칸 | 몸짓(`sceneTags`) |
| --- | --- |
| 1 기본 | 인물 자세 `charm.pose`(펜싱 자세·방패·허리에 손 등) |
| 2 웃음 | 크게 웃으며 손을 가슴에 |
| 3 부끄러움 | 옆을 보며 볼에 손 |
| 4 슬픔 | 고개 숙이고 눈물 닦기 |
| 5 놀람 | 두 손 들기 |
| 6 분노 | 이를 악물고 주먹 쥐고 팔 내림 |
| 7 삐침 | 옆을 보며 팔짱 |
| 8 공포 | 자기 몸 감싸기 |
| 9 부상 | 붕대 감은 팔 붙잡기 |
| 10 회복 | 옅은 미소, 뒷짐 |
| 11 휴식 | 베개에 옆으로 누워 잠(구도 그대로) |
| 12 공격 | 전투 자세(인물의 무기) |
| 13 각성 | 손 뻗기 + 번개·기운 |
| 14 설렘 | 홍조, 손을 가슴에 |

- 서 있는 칸(1·3~10·14)은 `standing, (straight-on:0.8)` — 기울어진 구도를 막음. 대신 몸짓이 약해지는 일이 있음(시험 7장 중 2장).
- 여성 인물은 성인 가중 1.2, 네거티브에 `emotion.negExtra`(위 구도·클로즈업·원근·기울어진 구도·`(chibi:1.3)`). **치비 네거티브를 빼지 말 것**(전신과 같은 이유).
- 묶은 머리 인물(포니테일·땋은 머리·올림머리 — 반묶음은 아님)은 네거티브에 `(hair down:1.3), loose hair`, 포니테일 인물은 인물 태그 끝에 `(ponytail:1.2)`를 한 번 더 — 정사각에서 묶은 머리가 풀렸음.
- **휴식(11)**: 눈을 그리라는 태그를 모두 뺌(인물의 눈매·눈색, 화풍의 `(beautiful detailed eyes:1.2)`·`(detailed eyes:1.2)`·`detailed iris`, 소품도 뺌), 장면에 `(closed eyes:1.4)`, 네거티브에 `(open eyes:1.2)` — 눈 강조 문구 때문에 자면서 눈을 떴음.
- 시드가 구도를 거의 정합니다. 칸마다 시드 몇 개를 돌려 기울어진 구도·풀린 머리·약한 몸짓을 피해 고를 것.

## 전신(`fullBody`)

`(full body:1.2), standing, <자세>, looking at viewer, <표정>` — 자세는 `charm.pose`(펜싱 자세·방패·쌍권총·렌치·저격총·기도·약초 바구니·부채·장검·팔짱 등 인물마다 하나).

- 여성 인물은 **성인 가중 1.2**, 네거티브에 `(upper body:1.1), (portrait:1.1), close-up, cowboy shot, feet out of frame, (chibi:1.3), super deformed`.
- **치비 네거티브를 빼지 말 것**: 시험에서 겁먹은 큰 눈(`wide-eyed`) + 둥근 눈 인물이 아이 같은 비율로 나왔습니다. 그래서 단비의 표정도 `nervous smile`로 바꿨습니다.
- 위에서 본 각도는 넣지 않습니다. 배경 효과(후광·소용돌이)가 가슴 위보다 화려해집니다.
- 전신을 어디에 쓸지(표지·새 칸)는 아직 정하지 않았습니다.

## 비교 생성에서 안 것

- **매끈한 광택 태그가 붓·먹 결을 덮음** — 붓·먹 태그를 더해도 안 바뀌었고, 광택 태그를 빼야 결이 생김.
- 얼굴 태그 가중 1.4 → 눈썹이 덧그린 선처럼 뜸(1.15 그대로).
- 볼살(`round face` 양수)·화장 빼기로 앳되게 → 어색함(사용자). 성숙 태그를 줄이고 눈 화장을 옅게 하는 쪽이 맞았음.
- 흩날리는 머리·`round face` 네거티브 빼기·선 긋기 음영 0.8 → 거의 변화 없음.
- 물감 튀김 효과 → 변화 없음.
- 번개 `(lightning:0.8), electricity` → 눈색을 따라 인물마다 다른 색의 기운이 생김. 순한 인물(미소)은 거의 안 보이고, 전신에서는 당소소의 보라 무복이 흰 바지로 바뀜 → 프로필에만.

## 남은 흠

- 류건(RGN): 어두운 옷이라 얼굴이 따뜻하고 어두운 편.
- 서하진(SHJ): 고개가 많이 기울어짐.
- 보라 눈 인물(윤도경·윤해라·당소소)의 검은 머리에 보라빛이 조금 남음.
- 전신: 같은 시드에서 늘 위에서 내려다본 웅크린 구도가 나오는 인물이 있음(윤도경) — 시드를 바꿀 것. 얼굴이 작아 눈색이 덜 보임.
- 손등 물감·화상 흉터처럼 손에 있는 특징은 가슴 위 그림에서는 손이 안 보여 안 나옴.
- 감정 칸: 감정이 얼굴에 몰리는 칸(부끄러움·슬픔·공포·놀람)은 가슴~허리까지로 가까워짐. 류건은 눈색·옷 때문에 불꽃 효과가 자주 붙음. 묶은 머리 규칙은 한서윤·미소·윤해라로만 시험함(나머지 묶은 머리 인물은 같은 규칙을 그대로 적용).
